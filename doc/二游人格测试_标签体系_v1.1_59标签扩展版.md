# 二游人格测试｜标签体系 v1.1（59标签扩展版）

> 上游：P0 v0.4.1 / 题库 v0.4 / P1 标签规范 v1.0  
> 本版目标：在不改变24人格核心定义的前提下，把更多**二游特有、具体、好传播的玩家行为**放进标签层。  
> 当前总量：**59 个行为标签 = 原36个 + 新增23个**。

---

# 1. 标签扩容原则

标签值得加入，至少满足其中两项：

1. **二游特征明显**：抽卡、保底、专武、体力、活动商店、角色预养成、版本前瞻等。
2. **行为足够具体**：用户能直接回答“我会不会这样做”。
3. **不需要伪装成人格**：它描述具体习惯，不承担24人格主判定。
4. **有分享价值**：看到名称能产生“这也被测出来了”的感觉。
5. **跨多款二游仍可理解**：尽量不用单一游戏专有词。

不加入：

- 只是在重复某个人格名字的标签
- 很短暂的版本状态
- 需要推断现实消费能力、人格优劣的标签
- 过度依赖某一款游戏独有系统的标签

# 4. 新标签的关键边界

## 4.1 活动末日战神 ≠ 版本活动特种兵

```text
活动末日战神：
“临截止才集中清活动”

版本活动特种兵：
“大版本/大型活动本身会显著拉高投入”
```

前者是具体节律标签，后者是人格。

## 4.2 首日开荒员 ≠ 开服先遣队

```text
首日开荒员：
已经玩的游戏，每次大版本首日冲内容

开服先遣队：
新游戏开服第一时间入坑
```

## 4.3 素材预制员 ≠ 卡池规划师

```text
素材预制员：
确定要抽后，会提前刷养成材料

卡池规划师：
更上层的资源/保底/未来卡池决策模式
```

## 4.4 词条精修师 ≠ 本命雕刻师

词条精修师可以针对很多角色；本命雕刻师强调：

> 少数本命 + 长期纵向极深投入。

## 4.5 保底守门员 ≠ 屯屯鼠

```text
保底守门员：
资源有明确未来归属

屯屯鼠：
资源本身就倾向先留着
```

## 4.6 声优雷达 ≠ XP鉴赏家

XP鉴赏家更偏整体角色审美、人设与气质。

声优雷达说明：

> **声音 / CV 本身就是独立吸引力。**

## 4.7 PV逐帧员 ≠ 前瞻情报员

```text
PV逐帧员：
分析官方公开物料里的细节

前瞻情报员：
主动追爆料、测试服、前瞻情报
```

## 4.8 长评潜水员 ≠ 攻略课代表

长评潜水员可以完全不发言，只是：

> 喜欢消费深度分析内容。

攻略课代表需要：

> 主动把知识解释给别人。

## 4.9 托管省心派 ≠ 随心体验派

托管省心派只是：

> 对重复日常内容偏好自动/扫荡。

随心体验派是更稳定的：

> 不让奖励和完成度绑架体验。

# 7. 标签题量原则

新增标签不意味着每个人多答23题。

本轮只新增：

```text
T23～T30
共8道标签题
```

且全部按相关领域路由。

另外：

```text
C19=A → 可直接强触发 活动末日战神
C26=D → 可直接强触发 保底守门员
```

所以对应标签题可以跳过。

**正式硬题量上限继续保持44题，不因为标签扩容上调。**

# 8. 标签文案风格

推荐：

> “具体、带一点玩家梗，但不带贬义。”

例如：

- `体力清空官` 比 `体力焦虑症` 更合适
- `词条精修师` 比 `词条强迫症` 更合适
- `托管省心派` 比 `懒人自动党` 更合适

继续避免：

- 强迫症
- 上瘾
- 氪佬 / 穷鬼
- 菜
- 懒
- 云玩家（除非未来专门定义且用中性含义）
