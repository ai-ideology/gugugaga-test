# 0. 记号

```text
D1:+2    → D1 加 +2
S3:+1    → S3 加 +1
P1_raw=3     → P1 直接记 3
TAG:X    → 触发标签 X
P1:NA    → 本题对 P1 提供“不适用”证据，不计 D
PERS:X+2 → 对人格 X 的专属鉴别强支持（仅A题使用）
PERS:X-2 → 对人格 X 的专属鉴别强反对
```

题型权重：

```text
C：1.0
A：1.25
T：人格/S弱证据0.5；标签触发不降权
```

未写出的 S 贡献均为 0。

A 鉴别题的 Persona 分统一使用：

```text
PERS:+2 = 100
PERS:+1 = 75
PERS:0 / 未写 = 50
PERS:-1 = 25
PERS:-2 = 0
```

**A题中“未写某人格”不等于0分，而是50中性。**

Gate 题记录 `P_raw`；正式 Hard Gate 与后续自适应使用 `P_effective`。

> 题型：多选，选择 1～3 项，不排序。  
> M 不参与 Fit，只参与主人格 MainIndex 的 MotivationalSalience。

| 选项 | 对应 M |
|---|---|
| A 角色/抽卡/养成 | M1 |
| B 剧情/世界观 | M2 |
| C 战斗/高难/配队 | M3 |
| D 探索/收集 | M4 |
| E 长期经营/日常/资源 | M5 |
| F 社区/二创/联机 | M6 |
| G 新版本/新游/迁徙 | M7 |

后台：

```text
被选中的 M = 100

未选中：
P_effective >=2 → M=55
P_effective =1  → M=35
P_effective =0  → M=20
```

M01 不需要排序，不允许因为选择顺序产生权重差异。

# 6.5 隐藏档案 H01｜二游观察者

H01 不进入24人格 Fit 排名。

触发条件：

```text
ConfirmedRegularPersonaCount = 0
count(P_effective >= 2) = 0
count(P_effective >= 1) <= 2
ΣP_effective <= 3
LowParticipationEvidenceCount >= 3
HardFactContradiction = false
```

其中 `LowParticipationEvidenceCount` 来自不同领域的：

- Gate 低参与
- 验证题 E/明确“不参与”
- 低参与事实题

### 禁止

若出现：

```text
LOW_EVIDENCE
CONTEXT_SENSITIVE
INSUFFICIENT_FEATURES
```

但并不满足真实低参与条件，则不能触发 H01。

H01 仍然以：

> **SSS｜二游观察者**

展示。

# 8. 当前题库仍需文案层修订的地方

这不属于本文件评分逻辑，但已经发现：

1. 8维核心题多数仍保持 A→D 同方向，玩家可能逐渐猜到计分方向。
2. 正式题库建议每维至少 1 道做**语义反向题**，不是简单随机打乱按钮。
3. A06 的 D 选项仍略混入“强度经理人”语义，后续需要改成更纯粹的高难挑战结果取向。
4. 部分标签题比较直白，所以已经在评分侧降权，但文案仍可进一步情境化。
5. “男/女角色收藏家”等标签是事实偏好，不应反推现实性别、性取向或其他个人属性。

# 9. 本轮做出的重要决策

1. 评分键正式加入 S17「体验自主度」。
2. T 标签题对人格/S只有 0.5 权重。
3. C06“喜欢收藏很多角色”不等于 S2“完成主义”，不再错误加分。
4. T05“抄作业”不再直接给 D5 负分，因为高钻研玩家也会为效率抄答案。
5. 节奏免疫体必须同时有社区接触与独立判断，不能由“不看社区”触发。
6. 全收集派必须跨至少两个系统，不能由单一本命精养触发。
7. 卡池规划师必须至少两条计划证据，其中一条是延迟满足。
8. 多游排班师必须有“并行维护”直接事实，不能只因为轮游多。
9. Gate 与深度题冲突时允许恢复，不做一票否决。
10. MX 只决定主人格中心性，不改变共鸣人格是否成立。
