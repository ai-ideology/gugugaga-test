# 二游玩家人格测试｜自适应题库 v0.5（标签扩展版）

> 状态：P1.5 正式实现基线  
> 上游：P0 判定系统 v0.4 核心冻结版  
> 目标：**读起来轻、选起来快、仍然能区分人格。**

---

# 0. 本版改动原则

1. 一题只做一个主要判断，减少“如果……但是……同时……”的复合句。
2. 题干尽量控制在一眼能扫完的长度。
3. 选项使用玩家能直接代入的行为，不写抽象人格词。
4. 不为了“反向计分”故意把选项顺序打乱；每题内部仍保持自然递进。
5. 仅选取部分核心题做语义反向，后台反向计分，避免形成固定 A→D 规律。
6. `E/不适用` 在前端建议单独做成次级按钮，不和四个倾向选项抢视觉。
7. 标签题可以更直白，因为它们主要记录事实标签，不承担主人格决定。
8. 新增 C27、C28 两道**条件题**，只在需要区分时出现，不进入普通固定路径。

---

# 1. 前端展示规则

- **不要显示** G/C/A/T、维度名、人格竞争组、后台用途。
- 用户只看到题目、选项和轻量进度。
- 首屏提示一次即可：

> **没有标准答案，按你最常见的情况选。遇到不适用的场景可以直接跳过。**

- 多选题明确显示“最多选3项”或“可多选”。
- M01 的 H“没有特别不能缺”与其他选项互斥。
- “以上都比较少/都不是重点”与其他多选项互斥。
- M01 不放在 7 道 Gate 后立刻问；建议在用户完成 **8～10 道核心题后** 插入，降低连续“自我概括题”的问卷感。
- 核心题前端必须**跨维度交错出现**，不要连续显示 C01～C03、C04～C06 这种同维度三连题。

# 9. 语义反向题

本版选择 6 道，而不是机械要求 8 个维度全部反向：

```text
C08  D3
C11  D4
C14  D5
C17  D6
C19  D7
C23  D8
```

D1、D2 暂不强行反向，原因是这两组题本身已经非常直观，且存在多个 Hard Gate / CoreSeat 直接引用。为了“反向”去改变自然表达，收益小于额外认知负担。

> **原则：防猜题服务准确性，但不能让测试读起来像量表考试。**

# 11. 推荐前端出题节奏

文档为了维护方便按模块排列，但真实前端不要照文档顺序连续出题。

推荐：

```text
7 Gate 快速校准
↓
D1 / D7 / D4 / D2 / D8 / D5 / D6 / D3 交错
↓
继续补各领域核心证据
↓
约第15～18个总回答位置插入 M01
↓
根据候选动态插入 A / C27 / C28
↓
必要时补少量 T 标签题
```

同一维度原则上不要连续超过 2 题。

目的：

- 减少“这一组明显都在问同一件事”的考试感
- 降低用户主动维持前后答案一致的压力
- 让题目更像连续的二游情境，而不是量表分组
