# 4. P1 的关键内容决策

1. **固定人格文案和动态证据分开。**
2. “为什么是你”必须来自用户实际答案，不只复述人格定义。
3. 主人格默认展示3～5条行为证据。
4. 共鸣人格统一称“共鸣人格”，不叫第二人格/第三人格。
5. 共鸣人格后台不限数量，首屏只做视觉精选。
6. 标签后台不限数量；UI去重不改变后台事实。
7. 人格与具体极端标签可以共存，例如“日课打卡派 + 全勤打卡官”。
8. 完全同义内容首屏抑制，例如“世界观考古学家 + 设定考古学家”。
9. 心理学只属于解释层，不参与人格判定。
10. 统一使用“另一种游戏乐趣”，不使用“你最难理解的玩家”。
11. H01 二游观察者拥有完整正向结果，但不承担 LOW_EVIDENCE 兜底。
12. LOW_EVIDENCE 使用“目前最鲜明的档案信号”，不出现“测试失败”。
13. 分享卡不出现伪精确匹配率。
14. 分享卡可用1个强标签替换1个固定高光，让同人格分享卡有个体差异。
15. 所有文案只讨论二游场景，不越界推断现实人格、智力、职业能力或临床状态。

# 8. P1讨论项已确认

## 8.1 人格名字

核心定义继续冻结。

人格名称不再内部凭感觉反复修改；在20～30人认知测试中加入：

> “只看名字，你觉得这是什么样的玩家？”

只有理解率明显偏低或误解集中时才改名。

## 8.2 多面体验派

暂不改名。

把“是否有二游味、是否一眼能懂”交给认知测试验证。

## 8.3 二游观察者

隐藏揭晓显示：

```text
SECRET ARCHIVE
SSS
二游观察者
```

`SECRET` 只表示隐藏触发路径，不表示更高级或更稀有。

## 8.4 心理学小档案

桌面：

> 默认显示60～100字摘要。

移动端：

> 默认显示摘要；来源与较长解释折叠。

## 8.5 第一版分享卡

不显示共鸣人格。

保留：

- 主人格
- 一句话
- 高光
- 3～5标签
- 品牌与测试入口
