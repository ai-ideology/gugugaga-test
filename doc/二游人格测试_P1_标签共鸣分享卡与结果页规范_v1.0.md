# 二游人格测试｜P1 标签、共鸣、分享卡与结果页内容规范 v1.0

> 目标：解决“标签很多时怎么展示”“人格与标签重复怎么办”“分享卡写什么”“共鸣人格怎么组织”等内容层问题。

---

# 1. 标签不限制后台数量

```text
后台：0～N
结果页精选：5～8
分享卡：3～5
完整档案：全部
```

UI可以折叠，但不能为了整齐删除真实触发标签。

---

# 2. 标签优先级算法

```text
TagDisplayScore =
4 × TriggerConfidence
+ 3 × Distinctiveness
+ 2 × Complementarity
+ 2 × Shareability
- 4 × SemanticRedundancy
- 5 × ContradictionRisk
```

## TriggerConfidence

- 1.0：事实型极端答案直接触发
- 0.75：一个主答案 + 侧证据
- 0.5：弱候选

## Distinctiveness

越具体越高：

```text
摄影师 > 喜欢探索
男角色收藏家 > 角色偏好明显
全勤打卡官 > 习惯常驻
```

## Complementarity

能补充主人格新信息的标签优先。

# 3. 标签去重规则

## A｜完全同义

默认抑制首屏。

例：

> 世界观考古学家 + 设定考古学家

后台都保留。

## B｜人格 + 具体极端行为

可以同时展示。

例：

> 日课打卡派 + 全勤打卡官

一个是稳定模式，一个是具体事实。

## C｜看似反差但可共存

允许。

例：

> 卡池规划师 + 屯屯鼠

## D｜真正强矛盾

先进入P0矛盾处理，不靠UI隐藏。

例：

> 卡池规划师 + 抽卡行动派（有多少抽多少）

# 5. 共鸣人格展示

后台所有“已确认人格”均保留。

## 结果首屏

最多显示 3～5 个最鲜明共鸣：

```text
ResonanceDisplayScore =
0.55 × Fit
+ 0.25 × EvidenceQuality
+ 0.20 × ComplementarityToMain
```

### ComplementarityToMain

- 跨领域、补充新信息：100
- 同领域但描述不同层面：75
- 与主人格非常近义：40

## 完整档案

展示全部，不限数量。

---

# 6. 不叫“第二人格 / 第三人格”

统一使用：

> **你的共鸣人格**

原因：

> 它们是真实成立的其他原型，不只是输给第一名的备选答案。

# 7. 分享卡结构

推荐 3:4 或 9:16。

```text
[二游人格档案]
SSS

[人格大图]

人格名
一句话

高光特质 × 3

精选标签 × 3～5

测测你的二游人格
[品牌 / QR / 网站]
```

不要展示：

- 完整8维
- 所有共鸣人格
- 伪精确百分比
- 未校准的“稀有度”

# 9. 分享卡高光特质可个性化

固定取人格3个高光，但允许用一个强标签替换其中1个。

例如：

```text
主人格：本命真爱党
固定：
核心席位明确 / 喜欢稳定 / 情感价值优先

触发：
#本命应援官

分享卡：
核心席位明确 / 喜欢稳定 / 本命应援官
```

这样同一人格的分享卡也能有差异。

# 10. 标签超过8个时分组

自动分为：

```text
角色与抽卡
养成与战斗
剧情与探索
游戏节律
社区与创作
```

空分组不显示。

# 11. H01 二游观察者 UI

仍使用 SSS 金色揭晓，但可以加：

```text
SECRET ARCHIVE
SSS
二游观察者
```

`SECRET` 只代表隐藏触发方式，不代表更高级。

分享卡可写：

> **隐藏档案已解锁**

不能写：

> “比普通人格更稀有”

除非未来真实数据支持并决定公开分布。

---

# 12. LOW_EVIDENCE 不生成隐藏人格

LOW_EVIDENCE 仍显示当前最鲜明的常规人格角色。

轻提示：

> **部分档案信号较少**

禁止：

> 隐藏人格：数据不足

# 13. 结果页内容优先级

## 必须保留

1. 主人格
2. 一句话
3. 高光特质
4. 为什么是你
5. 8维光谱
6. 精选标签

## 次级

7. 共鸣人格
8. 心理学小档案
9. 另一种游戏乐趣

## 可折叠

10. 全部标签
11. 完整证据
12. 详细共鸣人格

# 14. P1 内容验收标准

- [ ] 10秒内能看懂人格名与一句话
- [ ] 三个高光不是同义词
- [ ] “为什么是你”至少有3条真实答案证据
- [ ] 没有从游戏行为推断现实人格诊断
- [ ] 没有“更理性/更专情/更高级”暗示
- [ ] 心理学模块不超过主文案信息量
- [ ] 反差人格文案没有敌意
- [ ] 分享卡不出现伪精确概率
- [ ] 共鸣人格数量不被算法层硬砍
- [ ] 标签重复只做UI抑制，不删除后台事实
