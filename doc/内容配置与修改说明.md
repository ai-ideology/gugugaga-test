# 内容配置与修改说明（身份系统 v0.6.1）

> 命名约定：面向玩家的产品文案统一使用“人格”（人格测试、人格图鉴、人格档案、核心人格、共鸣人格）；工程内部继续沿用稳定的 `identity` 类型、字段、路由和资源目录名，以兼容评分规则、历史存档与现有素材。

当前工程已从“24+1 人格”切换到“36 底层特征 → 11 Family → 73 身份”的动态身份系统。题目和身份基础信息以“方案”目录中的冻结文档为单一来源，页面不再重复维护一份文案。

| 想修改的内容 | 修改位置 | 是否影响结果 |
|---|---|---|
| 题目、选项、NONE / NA 文案 | 方案/二游玩家身份测试_正式题库_v0.1.md | 只改显示文案通常不影响 |

当前视觉基线为 `Neo-Brutalist Playful`，硬规则来自 `theme/neo-brutalist-playful-hard-prompt.md`。全局样式不使用圆角卡片、模糊阴影、玻璃模糊或渐变色。

## 文档解析约束

- 题目标题必须保留 G01、K01、RT01、CF01 这类三级标题和代码格式。
- 每个选项表必须保留“选项 / 前台文案 / 后台 updates / Evidence”四列。
- 稳定题号、选项字母和 updates 路径不要只为润色文案而修改。
- 身份总表必须保留“身份 / 层级 / Mask / 底层特征公式 / 边界说明”五列。
- 结果文案必须保留 `### 序号. 身份名`、`典型行为`、`共鸣金句`、`身份描述长文` 四级结构；身份名必须与冻结表一致。
- NONE 表示真实不参与；NA / UNEXPOSED 表示没玩过或系统不存在，两者不能互换。

## 版本与验证

结果快照使用以下版本边界：

- 身份：0.6.1
- 特征：0.1
- 题库：0.1
- 判定引擎：1.0

每次修改题库、阈值或身份关系后，至少运行 npm test、npm run build 和 npm run test:e2e。

自动校验会检查 65 题、36 特征、73 身份、73 份结果文案、图片覆盖、确定性评分、NONE / NA 和主要页面流程。
