# 二游人格测试｜标签扩容设计说明 v1.0

## 结论

本轮将标签从 **36 → 59**。

没有扩人格数量，也没有改变24人格核心定义。

新增标签重点补齐八个此前覆盖不足的二游行为领域：

1. 体力 / 周常 / 活动商店
2. 大版本首日与活动截止节奏
3. 新角色预刷、速成和词条精修
4. 保底、专武与抽卡仪式
5. CV / 语音 / OST
6. 支线 / 隐藏成就
7. PV、官方前瞻、长评与梗图创作
8. 自动托管、手法练习与面板计算

## 为什么不扩成80～100个？

标签理论上可以很多，但第一版不宜无限扩：

- 标签越多，标签题越容易拖长测试
- 太细的标签会变成“游戏功能清单”
- 很多行为只在单一游戏存在
- 真实用户数据还没告诉我们哪些标签真正有传播价值

因此 v1.1 先停在59个。

等真实公测后再看：

```text
触发率
分享卡采用率
用户点击展开率
“这也被测出来了”的反馈
```

再决定第二批扩展。
